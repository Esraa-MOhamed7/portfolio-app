# Machine Learning & AI Engineering Portfolio

A modern, light-themed, high-performance personal portfolio showcasing practical Artificial Intelligence models, Natural Language Processing (NLP) pipelines, Retrieval-Augmented Generation (RAG) systems, and AI automation workflows.

---

## 🛠️ Tech Stack & Architecture

- **Frontend & UI:** React, TypeScript, Tailwind CSS, Vite
- **AI & ML Tools:** PyTorch, Hugging Face, Scikit-learn, LangChain, LangGraph, ChromaDB
- **Backend & Automation:** FastAPI, Flask, n8n Automation Workflows, Docker Containerization
- **Deployment:** Vercel

---

## 🌟 Featured Projects

1. **MedNER (Medical Named Entity Recognition)**
   - Fine-tuned BERT model for medical entity recognition, deployed as a containerized FastAPI service.
2. **Production-Ready RAG Pipeline with Guardrails**
   - Document Q&A system built with LangChain, LLaMA-3, ChromaDB, dynamic chunking, and strict hallucination guardrails.
3. **Amazon Review Sentiment Analysis & Automation**
   - End-to-end sentiment classification workflow using PyTorch inference connected via n8n webhooks to Google Sheets.
4. **LangGraph Intelligent Agent Workflow**
   - Multi-branch agent state-graph featuring double interrupt points for human-in-the-loop validation.
5. **10-K Financial Reports RAG Assistant**
   - Financial intelligence assistant with query rewriting, transformation, and context reranking.
6. **Customer Segmentation with RFM Analysis & Automation**
   - Unsupervised K-Means clustering integrated with automated n8n Telegram notification routing.
7. **Hourly Energy Demand Forecasting**
   - Predictive time-series machine learning model for power consumption evaluation.
8. **Suicide and Depression Detection**
   - Deep learning NLP text classification pipeline analyzing context and emotional intent.
